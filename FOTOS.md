# Quick-tips voor de foto's

- **Licht:** daglicht is je vriend. Bij een raam = altijd beter dan kunstlicht.
- **Achtergrond:** rustig. Niet te druk.
- **Compositie:** rule-of-thirds. Niet altijd recht in het midden.
- **Echt > gepolijst:** het moet op jou lijken, niet op een LinkedIn-stockfoto.
- **50-80% eigen foto's** is een harde eis van de opdracht — dus de meeste moeten door jou gemaakt zijn, niet gestocked.
